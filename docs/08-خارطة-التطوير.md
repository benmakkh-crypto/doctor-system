# خارطة التطوير

| الإصدار | المحتوى | الهدف |
| --- | --- | --- |
| **3.0** (الحالي) | Apps Script، وبوابة دخول، وصلاحيات على الخادم، وتدقيق، ومرفقات، ونسخ احتياطي، وبريد | تشغيل تجريبي لشهر |
| **3.1** | أرشفة سنوية إلى جدول منفصل؛ وتقارير تقرأ وحداتها الخاصة (الإعانة، المتابعة)؛ وطباعة سند قبض وصرف بصيغة PDF | بعد ملاحظات الشهر الأول |
| **3.2** | رمز دخول لمرة واحدة عبر البريد (مصادقة ثنائية) للمسؤولين؛ ورسائل نصية عبر مزوّد سعودي؛ وتذكير يومي بالمتأخرات | ربع سنة |
| **3.3** | سلسلة اعتماد متعددة المستويات (رئيس اللجنة ثم اللجنة المختصة)؛ ونماذج قرارات المساعدات | ربع سنة |
| **4.0** | خادم مخصص وقاعدة بيانات علائقية، وbcrypt، وواجهة برمجية للربط مع البنك والمنصة الوطنية للعمل الخيري (إحسان) | عند تجاوز 10,000 معاملة سنويًا أو 30 مستخدمًا |

**قاعدة الانتقال:** لا يُنتقل لإصدار قبل أن يمر الإصدار الحالي بقائمة القبول اليدوية في [07 خطة الاختبار](07-خطة-الاختبار.md) دون ملاحظات حرجة.
