# التثبيت والنشر

الوقت المتوقع: 15 دقيقة. تحتاج حساب Google، ويفضَّل حساب مؤسسي مخصص للجمعية.

## الطريقة الأولى: النسخ واللصق (بلا أدوات)

1. **افتح مشروعك** في Apps Script:
   https://script.google.com/home/projects/1r6FuCZ7UOKhRxDBWlEwxnmwbTfi4JjUV4MnFuc1Rx2DYGhgDRueBKlPb/edit
2. **ملف `Code.gs`**: افتح الملف الموجود (قد يكون اسمه `Code.gs` أو `الرمز.gs`)، واحذف محتواه، والصق محتوى `src/Code.gs` من هذا المستودع.
3. **ملف `Schema.gs`**: اضغط **＋** بجوار «الملفات»، ثم **نص برمجي**، وسمّه `Schema` بلا امتداد، والصق محتوى `src/Schema.gs`.
4. **ملف `Index.html`**: اضغط **＋**، ثم **HTML**، وسمّه `Index` تمامًا بلا امتداد، والصق محتوى `src/Index.html`.
5. **ملف الإعدادات**: من **إعدادات المشروع** (رمز الترس) فعّل «إظهار ملف البيان appsscript.json في المحرر». ثم افتح `appsscript.json` من قائمة الملفات، والصق محتوى `src/appsscript.json`.
6. **احفظ** بـ Ctrl+S.
7. **التثبيت**: من القائمة أعلى المحرر اختر الدالة `setup` واضغط **تشغيل**.
   - ستُطلب الموافقة على الصلاحيات (Sheets وDrive والبريد والمشغّلات). اضغط **مراجعة الأذونات**، ثم اختر حسابك.
   - إن ظهر «لم تتحقق Google من هذا التطبيق» فاضغط **خيارات متقدمة** ثم **الانتقال إلى المشروع**؛ هذا طبيعي لأن المشروع مشروعك أنت.
   - من **سجل التنفيذ** أسفل الشاشة انسخ: اسم المستخدم `zubair` وكلمة المرور المؤقتة.
8. **النشر**: اضغط **نشر** ← **نشر جديد** ← رمز الترس ← **تطبيق ويب**.
   - الوصف: `الإصدار 3.0.0`
   - التنفيذ باسم: **أنا**
   - من يمكنه الوصول: **أي شخص**
   - اضغط **نشر** وانسخ **رابط تطبيق الويب** (ينتهي بـ`/exec`).
9. **الدخول**: افتح الرابط، وادخل بـ`zubair` وكلمة المرور المؤقتة، واختر كلمة مرورك.
10. **الضبط الأولي**: من «الإعدادات والبيانات» اكتب اسم الجمعية وحد الاعتماد. ومن «المستخدمون» أضف فريقك.

> **لماذا «أي شخص»؟** لأن النظام له بوابة دخول خاصة به، فلا يحتاج الموظف حساب Google. كل المحتوى خلف تسجيل الدخول.

## الطريقة الثانية: clasp (للمطوّرين)

```bash
npm install -g @google/clasp
clasp login
git clone https://github.com/benmakkh-crypto/doctor-system && cd doctor-system
clasp push            # يرفع محتوى src/ إلى المشروع المربوط في .clasp.json
```

ثم أكمل من الخطوة 7 أعلاه. يتطلب clasp تفعيل «Google Apps Script API» من https://script.google.com/home/usersettings

## التحديث لإصدار جديد

1. الصق الملفات الجديدة (أو `clasp push`).
2. **نشر** ← **إدارة عمليات النشر** ← قلم التعديل ← **الإصدار: إصدار جديد** ← **نشر**.
3. يبقى الرابط نفسه، وتبقى البيانات كما هي. لا تشغّل `setup` مرة ثانية إلا إذا طُلب في ملاحظات الإصدار؛ وهي آمنة إن شُغّلت، لأنها لا تمسح شيئًا.

## الطوارئ

| الحالة | الحل |
| --- | --- |
| نسي المسؤول كلمة المرور | من المحرر شغّل `resetAdminPassword` وانسخ الكلمة المؤقتة من السجل |
| «النظام غير مثبّت بعد» | شغّل `setup` |
| فقد بيانات أو تعديل خاطئ | Drive ← «نظام الدكتور» ← «النسخ الاحتياطية»، وافتح نسخة اليوم السابق، وانسخ الأوراق المطلوبة |
| النظام بطيء | راجع عدد المعاملات؛ فوق 10,000 يُنصح بالأرشفة (انظر خارطة التطوير) |
| لا تصل رسائل البريد | تأكد من إدخال بريد المستخدم، ومن تفعيل الإشعارات في الإعدادات. الحد 100 رسالة يوميًا للحساب المجاني |

## ما ينشئه `setup`

- جدول «قاعدة بيانات نظام الدكتور» بسبع أوراق.
- مجلد «نظام الدكتور» في Drive، وفيه «المرفقات» و«النسخ الاحتياطية».
- مشغّل يومي الساعة 2 فجرًا للنسخ الاحتياطي.
- الإعدادات الافتراضية، وحساب `zubair`.
