# دليل المستخدم

## أول دخول

1. افتح الرابط الذي أرسله لك مسؤول النظام.
2. اكتب اسم المستخدم وكلمة المرور المؤقتة.
3. اختر كلمة مرور خاصة بك: 8 أحرف على الأقل، فيها حروف وأرقام. يُظهر لك المؤشر قوتها.
4. فعّل «تذكرني» على جهازك الشخصي فقط، لا على جهاز مشترك.

بعد 5 محاولات خاطئة يُقفل الحساب 15 دقيقة. وإن نسيت كلمة المرور فاطلب من المسؤول كلمة جديدة.

## العمل اليومي للموظف (المساهم)

| أريد أن… | الطريقة |
| --- | --- |
| أسجّل تبرعًا أو طلب إعانة بسرعة | الرئيسية ← البطاقات السريعة في الأعلى |
| أضيف معاملة في أي وحدة | زر «＋ معاملة جديدة» الذهبي، ثم اختر الإدارة والوحدة |
| أعرف ما عليّ اليوم | «مهامي والأولويات»: الموجّه إليك، والمصعّد، والمتأخر، وما يستحق خلال أسبوع |
| أجد معاملة | اضغط «/» واكتب رقمها أو اسم الداعم أو المستفيد |
| أحرّك معاملة للمرحلة التالية | افتحها ← «الإجراءات»، أو اسحب بطاقتها في «لوحة مراحل» |
| أطلب اعتماد مبلغ كبير | افتحها ← «رفع للاعتماد»، فيصل للمسؤول بريد |
| أحيل معاملة لزميل | افتحها ← «توجيه» ← اختر الزميل، واكتب التعليمات والموعد |
| أنبّه إلى أمر عاجل | افتحها ← «تصعيد» ← عاجلة أو حرجة، مع السبب |
| أرفق سندًا أو صورة هوية | افتحها ← «＋ إرفاق ملف» (PDF أو صورة، حتى 5 م.ب) |
| أسجّل ما تم | افتحها ← اكتب في «المتابعة» ← «إضافة ملاحظة» |
| أحذف خطأً | افتحها ← «حذف»، ولديك 7 ثوانٍ لضغط «تراجع»، وبعدها تجدها في «المحذوفات» |
| أصدّر جدولًا إلى Excel | من أي جدول ← «تصدير Excel (CSV)» |

**معاني الألوان:** أزرق جديد، وبرتقالي قيد المتابعة، وبنفسجي بانتظار الاعتماد، وأخضر مكتمل، وأحمر مرفوض. الشريط الأحمر على جانب الصف يعني حرجة، والبرتقالي عاجلة.

**إن ظهر زر معطّل** فاقرأ السطر تحته، فهو يشرح السبب، مثل: «القرار لمسؤولي النظام لأن القيمة 12,000 ر.س تبلغ حد الاعتماد».

## مهام المسؤول

| المهمة | المكان |
| --- | --- |
| اعتماد الطلبات أو رفضها | «صندوق الاعتمادات»، بضغطة لكل طلب |
| إضافة موظف | «المستخدمون» ← «＋ مستخدم جديد» ← سلّمه البيانات التي تظهر لمرة واحدة |
| حصر موظف في إدارات | «المستخدمون» ← «تعديل» ← حدد الإدارات |
| إيقاف موظف غادر | «المستخدمون» ← «تعديل» ← ألغِ «الحساب نشط»، فيُغلق وصوله فورًا |
| نسي موظف كلمة المرور | «المستخدمون» ← «كلمة مرور جديدة» |
| تغيير حد الاعتماد وفصل المهام | «الإعدادات والبيانات» |
| مراجعة من فعل ماذا | «سجل التدقيق» |
| نسخة احتياطية فورية | «الإعدادات والبيانات» ← «نسخة احتياطية في Drive الآن» |
| تنظيف بيانات التجربة | «الإعدادات والبيانات» ← «حذف البيانات التجريبية» |

## اختصارات

| المفتاح | الوظيفة |
| --- | --- |
| / | البحث الشامل |
| Esc | إغلاق النافذة أو اللوحة |
| Enter على صف | فتح المعاملة |
| أ− / أ+ | تصغير الخط أو تكبيره |
| تركيز | إخفاء القائمة والتركيز على مهامك |
