# نموذج البيانات

تُحفظ البيانات في جدول Google Sheets اسمه «قاعدة بيانات نظام نافذ»، داخل مجلد «نظام نافذ» في Drive حساب المالك. **لا تعدّل الجدول يدويًا**؛ كل كتابة يجب أن تمر عبر النظام ليبقى سجل التدقيق صادقًا. كل الخلايا منسقة نصًا خامًا، فلا يحوّل Sheets المعرّفات أو كلمات المرور المشفّرة إلى أرقام.

## الأوراق

| الورقة | الأعمدة | سطر لكل |
| --- | --- | --- |
| المستخدمون | username, name, email, role, depts, active, salt, hash, failed, lockedUntil, mustChange, lastLogin, created | مستخدم |
| المعاملات | id, no, g, m, status, deleted, updated, json | معاملة |
| القرارات | id, s, by, at, amt, note | قرار اعتماد فوق الحد |
| الإعدادات | key, value (JSON) | إعداد |
| سجل_التدقيق | at, user, action, recordId, no, detail | عملية |
| العدادات | key, value | إدارة وسنة (مثل FIN-2026) |
| المرفقات | id, recordId, name, mime, size, driveId, by, at | ملف |

### المستخدمون

| العمود | المعنى |
| --- | --- |
| username | حروف إنجليزية صغيرة وأرقام و`._-`، من 3 إلى 30 حرفًا |
| role | `admin` أو `contributor` أو `viewer` |
| depts | أرقام الإدارات المسموحة مفصولة بفواصل؛ الفارغ يعني كل الإدارات |
| salt, hash | ملح عشوائي، وتجزئة SHA-256 مكررة 400 مرة. لا تُحفظ كلمة المرور نفسها |
| failed, lockedUntil | عدّاد المحاولات الخاطئة ووقت انتهاء القفل |
| mustChange | يُطلب تغيير كلمة المرور عند الدخول |

### المعاملات (عمود json)

| الحقل | المعنى |
| --- | --- |
| id | معرّف فريد UUID |
| no | الرقم التسلسلي `FIN-2026-00042` |
| g, m | رقم الإدارة ورقم الوحدة (من Schema.gs) |
| title, owner, notes | العنوان والمسؤول نصًا والملاحظات |
| status | جديد، قيد المتابعة، بانتظار الاعتماد، مكتمل، مرفوض |
| pri, esc | الأولوية (0 عادية، 1 عاجلة، 2 حرجة) وعدد مرات التصعيد |
| date, due | تاريخ المعاملة والاستحقاق بصيغة YYYY-MM-DD |
| to | اسم المستخدم الموجّهة إليه |
| f | الحقول الخاصة بالإدارة (الجدول أدناه) |
| files | قائمة المرفقات: id, name, mime, size, by, at |
| flags | `split` عند الاشتباه بتجزئة مبلغ |
| hist | آخر 60 إجراءً: at, by, a (الإجراء), t (النص), to |
| created, createdBy, updated, updatedBy | يختمها الخادم من الجلسة |
| deleted, deletedAt, deletedBy | الحذف المؤقت |
| sample | بيانات تجريبية |

**القيمة المالية للمعاملة** = amount + budget + monthly (ما وُجد منها). هي التي تُقارن بحد الاعتماد.

### الإعدادات

| المفتاح | النوع | الافتراضي |
| --- | --- | --- |
| orgName | نص | فارغ |
| threshold | رقم (ر.س) | 5000 |
| sod | منطقي: فصل المهام | false |
| notify | منطقي: إشعارات البريد | true |

### خصائص المشروع (Script Properties)

| المفتاح | المحتوى |
| --- | --- |
| SPREADSHEET_ID | معرّف الجدول |
| FOLDER_ID, FILES_FOLDER_ID, BACKUP_FOLDER_ID | مجلدات Drive |
| REV | رقم المراجعة؛ يتغير مع كل كتابة لتعرف الواجهات متى تُحدِّث |
| s_… | جلسات «تذكرني» مفهرسة بتجزئة الرمز، لا بالرمز نفسه |

## التصنيف التفصيلي (منذ 3.1.0)

لكل إدارة في `SCHEMA.G` أربعة حقول عرض إضافية:

| الحقل | المحتوى |
| --- | --- |
| `col` | لون الإدارة (تباين 4.5:1 على الأقل مع الأبيض) |
| `en` | الاسم بالإنجليزية |
| `sec` | العناوين الفرعية: `[العنوان، [أرقام الوحدات]]`، وكل وحدة في عنوان واحد |
| `idesc` | وصف كل وحدة، بترتيب `items` نفسه |

المصدر `tools/taxonomy.js`، ويُدمج بالأمر `node tools/apply-taxonomy.js`. لا يُغيَّر ترتيب `items` لأن المعاملات تحفظ رقم الوحدة.
