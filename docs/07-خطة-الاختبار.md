# خطة الاختبار

## الاختبارات الآلية

في مجلد `tests/`:

| الملف | ما يفعله |
| --- | --- |
| `gas-mock.js` | يحاكي خدمات Google (Sheets وProperties وCache وLock وDrive وMail وUtilities)، ويحمّل `Code.gs` و`Schema.gs` كما يحمّلهما Apps Script |
| `server.test.js` | 48 اختبارًا على الخادم |
| `ui.test.js` | يشغّل `Index.html` في Chromium موصولًا بالخادم المحاكى، ويلتقط صورًا للشاشات |

```bash
cd tests
node server.test.js
NODE_PATH=$(npm root -g) node ui.test.js     # يتطلب: npm i -g playwright
```

### ما يغطيه اختبار الخادم (48 تأكيدًا)

- **الدخول:** رفض كلمة المرور الخاطئة، واسم المستخدم غير حساس لحالة الأحرف، والتغيير الإجباري، وسياسة كلمة المرور، والقفل بعد 5 أخطاء، ورفض الكلمة الصحيحة أثناء القفل، وإبطال الرمز بالخروج، ورفض الرمز المزوّر.
- **المستخدمون:** صيغة الاسم، ومنع المسؤول من تنزيل نفسه، وكلمة مؤقتة لكل حساب.
- **الصلاحيات:** حصر المساهم في إداراته قراءةً وكتابة، ومنع المشاهد من الكتابة والمرفقات وقائمة المستخدمين، وإخفاء الهوية للمشاهد.
- **الاعتماد:** منع المساهم فوق الحد، وإلزامية سبب الرفض، وتسجيل القرار، وإشعار المنشئ، وعودة المعاملة لانتظار الاعتماد عند تغيير المبلغ، وفصل المهام.
- **سلامة البيانات:** الترقيم التسلسلي، ومنع تكرار سند القبض، والتحقق من الجوال والقوائم على الخادم، وكشف التعديل المتزامن، وكشف التجزئة.
- **دورة الحياة:** التوجيه، والتصعيد، والملاحظات، والحذف والاستعادة، ومنع المساهم من الحذف النهائي.
- **المرفقات:** الرفع، وتقييد النوع، والتنزيل سليمًا.
- **الإدارة:** سجل التدقيق، والاستيراد مع رفض الصفوف التالفة، وإفراغ المحذوفات، وحذف البيانات التجريبية.

### ما يغطيه اختبار الواجهة

بوابة الدخول على الحاسب، ورسالة كلمة المرور الخاطئة مع عدد المحاولات المتبقية، والدخول، والرئيسية، ولوحة المعاملة، والاعتماد من الصندوق، وإنشاء مستخدم وعرض كلمته المؤقتة، وخطأ الجوال تحت حقله، وإنشاء معاملة برقم تسلسلي، وسجل التدقيق، والخروج. ثم على جوال (390 بكسل) في الوضع الداكن: التغيير الإجباري لكلمة المرور، وظهور الإدارات المسموحة فقط، وعدم وجود تمرير أفقي. والنتيجة صفر أخطاء في وحدة التحكم.
